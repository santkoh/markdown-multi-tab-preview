# Color Swatch Test

## 色として表示されるべき
- `#ff0000` (red)
- `#3af` (short hex — a-f を含む)
- `#abcd` (4桁 alpha)
- `#fff` (f は a-f に該当するため表示)
- `rgb(255, 100, 50)`
- `rgba(0, 0, 0, 0.5)`
- `hsl(120, 50%, 50%)`
- 文中の #f00 や #abc も swatch 表示
