# CJK / ASCII アート 桁ズレ検証

このファイルは「エディタでは揃って見えるのに Preview で `│` がズレる」現象の切り分け用。
各ケースを **エディタ** と **Preview** の両方で見比べ、どこで崩れるかを確認する。

---

## ケース A: 純 ASCII のみ（日本語なし）

> 期待: エディタ・Preview の **両方で揃う**。崩れたら font-family がフォールバックで等幅でなくなっている。

```text
+------------------+------------------+
| Name             | Status           |
+------------------+------------------+
| alpha            | OK               |
| bravo            | FAILED           |
| charlie          | PENDING          |
+------------------+------------------+
```

```text
┌──────────────────┬──────────────────┐
│ Name             │ Status           │
├──────────────────┼──────────────────┤
│ alpha            │ OK               │
│ bravo            │ FAILED           │
└──────────────────┴──────────────────┘
```

---

## ケース B: 日本語ラベル混在（半角罫線 `│`）

> 期待: エディタでは揃うが、Preview では日本語の入った行だけ右の `│` が**ズレる**。
> これが CJK フォールバックによる送り幅不整合（本命）。

```text
┌──────────────────┬──────────────────┐
│ 名前             │ 状態             │
├──────────────────┼──────────────────┤
│ アルファ         │ 正常             │
│ ブラボー         │ 失敗             │
│ チャーリー       │ 保留中           │
└──────────────────┴──────────────────┘
```

---

## ケース C: UI モックアップ（日本語ボタン・見出し）

> 実際の画面再現に近いケース。縦の `│` がガタつくはず。

```text
┌─────────────────────────────────────────┐
│  ＭｙＡｐｐ                      [ 設定 ] │
├─────────────────────────────────────────┤
│  ┌───────────┐  ┌───────────┐           │
│  │  新規作成  │  │  読み込み  │           │
│  └───────────┘  └───────────┘           │
│                                         │
│  検索: [____________________] [ 実行 ]   │
└─────────────────────────────────────────┘
```

---

## ケース D: 全角縦棒 `｜`(U+FF5C) を区切りに使用

> 全角の `｜` と全角スペースだけで組んだ表。CJK 等幅フォントなら揃い、
> そうでなければ全体が崩れる。

```text
　名前　　　｜　状態　　　｜　担当
　アルファ　｜　正常　　　｜　田中
　ブラボー　｜　失敗　　　｜　佐藤
　チャーリー｜　保留　　　｜　鈴木
```

---

## ケース E: 半角・全角混在（最も崩れやすい）

> 1行の中で半角英数と全角を混ぜると端数が累積する。

```text
| id   | 名称(JP)     | qty | 備考                |
|------|--------------|-----|---------------------|
| 1001 | りんご       | 12  | 産地: 青森          |
| 1002 | バナナ       | 240 | import / フィリピン |
| 1003 | みかん(小)   | 8   | 訳あり              |
```

---

## 参考: Markdown のテーブル記法（崩れない）

> ASCII アートではなく Markdown のテーブルにすれば、HTML の `<table>` に
> 変換されるので桁ズレは原理的に発生しない（罫線をフォントで揃える必要がない）。

| 名前       | 状態   | 担当 |
|------------|--------|------|
| アルファ   | 正常   | 田中 |
| ブラボー   | 失敗   | 佐藤 |
| チャーリー | 保留中 | 鈴木 |
